# ⚡ YUMASHOP - Modern Game Top-Up Store

YUMASHOP adalah platform top-up voucher game dan produk digital modern, cepat, dan responsif yang terinspirasi dari UI/UX Codashop dan katalog Dayjhostore.

Built with **React**, **Vite**, and **Tailwind CSS**.

---

## ✨ Fitur Utama

- **Catalog Lengkap**: 128+ judul game populer (Mobile Legends, Free Fire, Valorant, Genshin Impact, Honor of Kings, Roblox, Steam, dll.) lengkap dengan poster ikon game.
- **Top-Up Flow 4 Langkah**:
  1. Input User ID & Zone ID / Server / Role
  2. Pilih Nominal / Denominasi (Diamonds, Genesis Crystals, Points, dll.)
  3. Pilih Metode Pembayaran (E-Wallet, Virtual Account Bank, Convenience Store, Pulsa) dengan kalkulasi biaya dan diskon harga real-time
  4. Beli & Konfirmasi instan
- **Metode Pembayaran Lengkap**:
  - **E-Wallet**: QRIS (All Payment), GoPay, DANA, OVO, ShopeePay, LinkAja, DOKU Wallet
  - **Virtual Account**: BCA, Mandiri, BRI (BRIVA), BNI, CIMB Niaga, Permata, Danamon, BNC (Neo Commerce), BSI
  - **Convenience Store**: Indomaret, Alfamart
  - **Pulsa / SMS**: Telkomsel, Indosat Ooredoo, Tri, XL Axiata
- **Desain & UI/UX Premium**:
  - Branding kustom: **YUMA SHOP** Cyber-cut Typography Logo & Emblem
  - 100% Vector SVG Icons (Zero Emoji UI)
  - Glassmorphic Unified Modals (Alert, Confirm, Prompt, Notification)
  - Shimmer Skeleton Loading states
  - Simulator Checkout & Invoice lengkap dengan QRIS NMID & hitung mundur 15 menit

## 🚀 Memulai (Getting Started)

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18+ disarankan)
- npm atau yarn / pnpm

### Instalasi & Menjalankan Dev Server

```bash
# Clone repository
git clone https://github.com/yudadwiptr/yumashop.git
cd yumashop

# Install dependensi
npm install

# Jalankan server lokal
npm run dev
```

Buka browser Anda di `http://localhost:5173`.

### Build untuk Produksi

```bash
npm run build
```

Hasil build akan berada di direktori `dist/` dan siap dideploy ke Vercel, Netlify, atau web hosting pilihan Anda.
